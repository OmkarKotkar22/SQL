DCL

DCL means Data Control Language.

Main commands:

GRANT
REVOKE

First create a database user

mysql> CREATE USER 'shop_user'@'localhost'
    -> IDENTIFIED BY 'Shop@123';
Query OK, 0 rows affected (0.04 sec)

Give SELECT permission

mysql> GRANT SELECT
    -> ON ecommerce_db.*
    -> TO 'shop_user'@'localhost';
Query OK, 0 rows affected (0.01 sec)

Give SELECT and INSERT

mysql> GRANT SELECT, INSERT
    -> ON ecommerce_db.*
    -> TO 'shop_user'@'localhost';
Query OK, 0 rows affected (0.01 sec)

Check permissions


mysql> SHOW GRANTS FOR 'shop_user'@'localhost';
+---------------------------------------------------------------------+
| Grants for shop_user@localhost                                      |
+---------------------------------------------------------------------+
| GRANT USAGE ON *.* TO `shop_user`@`localhost`                       |
| GRANT SELECT, INSERT ON `ecommerce_db`.* TO `shop_user`@`localhost` |
+---------------------------------------------------------------------+
2 rows in set (0.00 sec)

Remove INSERT permission


mysql> REVOKE INSERT

VIEW

A view is a virtual table based on a query.

Create a customer-order view

mysql> CREATE VIEW customer_order_view AS
    -> SELECT
    -> c.customer_id,
    -> CONCAT(c.first_name, ' ', c.last_name) AS "Customer Name",
    -> o.order_id,
    -> o.order_date,
    -> o.status,
    -> o.total_amount
    -> FROM customers c
    -> JOIN orders o
    -> ON c.customer_id = o.customer_id;
Query OK, 0 rows affected (0.02 sec)
